# Evidencia: la consulta de citaciones de la ANT no responde

| Campo | Valor |
|---|---|
| Fecha y hora | martes 17/11/2026, 11:14:49 (hora de Ecuador, UTC-5) · 16:14:49 UTC |
| Dirección consultada | https://consultaweb.ant.gob.ec/PortalWEB/paginas/clientes/clp_grid_citaciones.jsp?ps_tipo_identificacion=CED&ps_identificacion=1710034065&ps_placa= |
| Código de respuesta | **HTTP 502 Bad Gateway** |
| Cuerpo de la respuesta | `502 Bad Gateway` (título y texto de la página) |
| Encabezado `Date` del servidor | Tue, 17 Nov 2026 16:14:49 GMT |
| Segunda dirección probada | https://consultaweb.ant.gob.ec/PortalWEB/paginas/clientes/clp_criterio_consulta.jsp → también **502 Bad Gateway** |
| Cómo se probó | Navegador (carga de la página) y una segunda petición `fetch` sin caché desde la misma pestaña |

En la misma sesión, las APIs del SRI respondieron correctamente (HTTP 200):

| API | Resultado |
|---|---|
| `existePorNumeroRuc?numeroRuc=1710034065001` | `true` |
| `obtenerPorNumerosRuc?&ruc=1710034065001` | contribuyente `PERSONA NATURAL` |
| `obtenerPorNumerosRuc?&ruc=1790016919001` | contribuyente `SOCIEDAD` (se usa para probar el error 422) |
| `obtenerPorNumeroPlacaOPorNumeroCampvOPorNumeroCpn?numeroPlacaCampvCpn=PBX1234` | vehículo JMC JX1032D 2012 |
| `...numeroPlacaCampvCpn=ZZZ0000` | `{"mensajeServidor":{"texto":"El vehículo no existe"}}` (se usa para probar el 404) |

Conclusión: el fallo está en el servidor de la ANT (el proxy de entrada no obtiene respuesta del
servidor de aplicaciones), no en la forma de invocar el servicio. Por eso el microservicio `ms-ant`
usa el contrato simulado (`ANT_MODO=simulado`) y mantiene el adaptador real listo para cuando la ANT se recupere.
